## 记录方式

每份日报记录完成事项、主要结果、问题与限制、下一步及对应报告。实验数字来自阶段报告和完成记录，区分实测结果与机制推断；预热、诊断采样和正式窗口分别统计。尚未运行的计划不写成已完成结果。

当天补充进展时更新同一日期文件，保留已经报告的失败与限制。阶段报告和日报分别维护：阶段报告保留完整方法与证据范围，日报记录当日增量。

## 新建日报

使用以下结构，并在上表加入日期链接：

```markdown
# YYYY-MM-DD 工作日报

## 今日进展

## 主要结果

## 问题与限制

## 下一步

## 相关记录
```

日报经过脱敏后发布，不记录服务器连接信息、个人目录、密钥和硬件唯一标识。公开材料的范围见 [PUBLICATION.md](../PUBLICATION.md)。
