## 重新绘图

在安装 Matplotlib 与 Pillow 的 Python 环境中，从仓库根目录运行：

```bash
python tools/render_daily_figures.py
```

本次使用 Matplotlib 3.11.2、Pillow 13.0.0。脚本直接读取上述公开 JSON，生成 `daily/figures/` 中的三个 PNG，移除图片文本和 EXIF 元数据，不连接模型服务、不调用远端接口。中文字体优先选择本机可用的黑体字体，字体不同可能影响排版；发布前需检查图中文字。
